# Observed problems
- Inspect how well the current architecture covers cache optimization: which surfaces rebuild the system prompt and when, what each transition costs against the cached prefix, and whether any of it churns per turn. `/cache` now reports reads, writes and cold requests from the log (ADR-0059); read it after a day of work, then decide on `cache.prefixTtl`.

# Deferred
- Child agents, next step (ADR-0062): run the `agent` calls of one reply in parallel and collect them; a blocking `wait` for a child started earlier; a column linking a child session to its parent, so the session list can nest it; summing a child's tokens into the parent's counters. Then the question of whether a child's findings should enter the graph by themselves.
- Scenario authoring in the GUI: scenarios are directories of `NN-name.md` files with `title:` and `toolset:` frontmatter (`prompts/scenarios/`), editable only as files. An editor in the style of the identity editor — add, edit, reorder and delete phases, pick the toolset from the existing ones — would make them a thing a user writes. See ADR-0009 and ADR-0049.
- URI-scheme addresses for the case's own elements (`session://`, `evidence://`, `graph://`, …): a stable string that names an element of the case database from outside it, and that a person or the agent can quote in a chat as a quick reference. To be discussed before any ADR, because the concept may be wider than one tool. Questions to settle: whether it is first a *reference* grammar (what a transcript, the grid and the agent write when they point at something) and only then a *resolver* for tools; how it relates to the addressing that already exists (`#id` and `history_read` for entries, `FileRef` for files, the graph tools' ids); which tools could take it, given that the agent's `read`/`write`/`edit` use native paths, `reactor-agent` does not use `reactor-fs`'s `Vfs`, and a `bash` pipe cannot resolve a URI; how a scheme stays agreed with the database's foreign keys and stays clear of real paths. See ADR-0044, ADR-0046, ADR-0047, ADR-0050, ADR-0056.
